# 白いちびキャラ

- white_chibi.blend: 編集用Blenderファイル。カメラ、照明、背景付き。
- white_chibi.glb: キャラクターのみの汎用3Dモデル。
- chibi_preview.png: 斜めからのレンダリング。
- chibi_front.png: 正面からのレンダリング。
- create_chibi.py: Blender内蔵Pythonで再生成するスクリプト。

FACEコレクションを非表示にすると、顔のない白いマネキンになります。
頭・耳・体・顔パーツを分けてあります。体はボクセルで接合した滑らかなメッシュです。
静止モデルです。ボーン、アニメーション、制作向けのリトポロジーは含みません。
