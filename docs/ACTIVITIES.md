# 交流の遊び（2026-10-24）

部屋の「いっしょに遊ぶ」から開く。音声接続を停止し、クイズ・挨拶・カードはAPIキーなしで利用できる。会話へ戻ってPTTで再接続する。

- しぐさクイズ: 手振り、大きなうなずき、肩すくめから出題。キャラクターの動きを見て3択で回答。3問中3問正解でスタンプ。見直し・再挑戦可能、回答連打で加点しない。
- 会話のお題カード: 休日、旅、カフェなど6つのお題。直前と同じカードを連続で引かない。自動送信はせず、気に入ったお題を声で聞く。
- ごあいさつ: ボタンで手を振ってもらう。手の動作を自動認識する機能ではない。
- 交流スタンプ: 初会話、5回の会話、ごあいさつ、3部屋訪問、クイズ全問正解の5個。キャラクター別にローカル保存。部屋は重複カウントしない。実際のユーザー文字起こしと返答文字起こしが揃ったターンを会話としてカウントする。

Startでも交流進捗は保持。全ローカルデータ削除で消去。会話・記憶だけの削除では交流回数・部屋訪問・達成フラグは保持し、発言本文はこの進捗に保存しない。報酬で会話機能を制限しない。連続ログインや未達によるペナルティなし。
