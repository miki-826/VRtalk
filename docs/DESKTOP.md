# PC版の遊び方

Windows 64bit版: `QuestAI/Builds/Windows/WhiteRoom.exe`。exeだけでなく、Windowsフォルダー全体を同じ場所に置いてください。VRヘッドセットは不要です。

1. 起動して「設定」→「AI」→「OpenAI API Key」を開く。
2. 自分のAPIキーをコピーし、「貼り付け」またはCtrl+Vで入力。「保存」を押すまで確定しません。キーは伏字で表示します。
3. 「話しかけ方」→「マイク・再生を確認（4秒）」でPCのマイクとスピーカーを確認。
4. キャラクターと部屋を選んで開始。「会話に接続」後、Uを押しながら話し、離して返答を待つ。画面のPTTボタンの長押しでも操作できます。
5. 「動きを試す」では、接続・キーなしで動きを試せます。「言葉で指示する」に「ソファの後ろに行って」「部屋の真ん中に行って手を振って」のように入力すると、その通りに動きます。おもちゃは「おもちゃで遊ぶ」から。

## 操作

- 左クリック: メニュー・選択・保存。
- 右ボタンを押しながらマウス移動: 視点を回す。
- W/A/S/D・矢印キー: 部屋の中を移動（壁・家具・キャラクターの手前で止まり、壁沿いには滑って進む）。
- T: 押している間マウスの先の床に輪が出て、離すとその場所へ移動（テレポート）。緑は移動可、赤は不可。
- F: マウスの先を指さす。物を指すとキャラクターが見に行き、床を指すとその場所まで歩いて来る。
- H: 手を振る / C: しゃがむ・立つ（キャラクターが反応します）。
- 「あそこに行って」と頼むと、直前にFで指した床、なければ画面中央（視線の先）の床へ歩きます。
- U長押し: PTT。文字入力画面では録音を開始しません。
- 声を出せない時: 会話画面の「文字で話す」で入力し、Enterまたは「送信」。日本語IMEも使えます。
- APIキー以外の設定も物理キーボードで入力可能。貼り付けは入力欄を置き換えます。

## 保存と取り扱い

Windows版の会話・設定はUnityのpersistentDataPathに保存。APIキーは別のsecretsフォルダーにWindows DPAPI（CurrentUser）で暗号化します。同じWindowsユーザーでのみ復号でき、ゲームフォルダーには保存しません。キーをソースやログへ書き込みません。

Editor内のPlayは従来どおりキーをセッション内だけ保持。Windows版の保存データはEditor用の会話データと分けています。

PCとQuestの設定・キー・記憶は自動同期しません。Quest側の貼り付けは、その端末から読めるクリップボードがある場合に使用できます。PCのクリップボードがQuestへ自動転送される機能ではありません。

キー削除は設定 > プライバシー > APIキーをすべて削除。全データ削除は会話・進捗も消去します。クリップボードはアプリ側から自動消去しないため、不要になったキーは別の内容をコピーして置き換えてください。

実際の音声会話にはOpenAI APIの利用権限とインターネット接続が必要です。

追加操作: おもちゃの配置・キャラクターとの遊びは [PLAYGROUND.md](PLAYGROUND.md) を参照してください。
