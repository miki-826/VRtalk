# 指示どおりの動き・おもちゃ遊び・視覚・ロボット声（2026-10-24）

## 指示どおりに動く

会話の発言（声・文字とも）が確定するたびに、Jevの表情判断と並行して **OpenAI Responses API（`llmModel`、既定 gpt-4.1-mini）の構造化出力** で「動作計画」を作る。Jevは有限の選択肢しか返せない仕様なので、自由な動きの計画はOpenAI側で行い、Jevは表情・視線・自発的な反応を担当する。

- 計画は最大10ステップの順番実行。普通の会話なら空（動かない）。
- 入力: 発言、キャラ名、姿勢、部屋の物のID、おもちゃの状態、今見えている物、部屋の説明。
- 返答はスキーマで型を固定し、`MotionPlans.Validate` で未知のIDの除去、量・角度の上限、キーフレームの並べ替えを行う（モデルの出力をそのまま信用しない）。
- 実行は `MotionPerformer`。実行中は散歩・Jevの移動判断・しぐさへの自動反応が体を動かさない（表情だけ変わる）。
- 「止まって」「ストップ」「やめて」など短い停止指示は計画を待たず即停止。

動きの種類（`MotionAction`）:

| 種類 | 内容 |
|---|---|
| walk_to / approach_user / move / turn / follow_user | 物やおもちゃへ歩く、ユーザーへ近づく、前後左右へ何m、右へ何度・後ろ・ユーザーの方を向く、ついて行く |
| look_at / point / sit / crouch / stand / gesture / wait / stop | 見る、指さす、椅子・ソファ（なければ床）に座る、しゃがむ、立つ、うなずき等、待つ、止まる |
| motion（プリセット） | jump, bow, banzai, clap, dance, stretch, spin, shake_head, nod, wave_both, sit_floor, think, cheer |
| motion（custom） | **プリセットにない動きは、OpenAIが関節角度のキーフレームを作って実行**（頭・胸の3軸、両腕の前上げ/横上げ/肘、両脚の前上げ/膝、腰の沈み、体の持ち上げ）。回転はキャラ自身の軸基準なので、しろ・こはく・ロボのどのモデルでも同じ意味になる |
| おもちゃ | spawn_toy, roll, kick, throw_ball, bounce, fetch, pick_up, put_down, stack, knock_down, line_up, spin_toy, put_away |
| look_closely | 目のカメラで見て説明する（下の「視覚」） |

例:「ボールを出してこっちに転がして」→ ボールを出す → 回り込んでボールの後ろに立つ → しゃがんで押す → ユーザーの足元で止まる速さで転がす。「積み木を積んでから崩して」→ 歩いて行き5段に積む → 蹴って崩す。「右手を上げたまま左足で立って」→ custom キーフレーム。

## おもちゃ（会話はつながったまま）

「いっしょに遊ぶ」「おもちゃを置いて遊ぶ」で会話接続を切らないように変更。遊び画面にもPTTと文字入力を置いた。

- ボール: 転がり（一定の減速）、床での弾み、壁・家具・キャラ・ユーザーの足での跳ね返り、転がりに合わせた回転。狙った距離で止まる初速を計算。止まった位置で経路探索の障害物に戻る。
- 積み木: 5個が床に散らばった状態で出る。積む（5段）、崩す（飛び散って床に落ちる）、並べる。途中で止めても空中に残らない。
- 回転おもちゃ: 回すと減速しながら回る。
- 持つ・置く・持ってくる: 胸の前に持って歩く。
- ユーザー自身も、置いたおもちゃをクリック（Questはレーザー＋トリガー）してボールを転がす・塔を崩す・回すことができ、その出来事は会話へ伝わる。

## 視覚（`CharacterVision`）

1. **幾何学的な視野**（キー不要・端末内、0.2秒ごと）: 頭の位置から視野140°・7m以内で、家具（高さ30cm以上の障害物）に遮られていない物だけを「見えている」とする。背後で転がるボールは気づかない。
   - 出来事: おもちゃ／ユーザーが視界に入った、おもちゃが動き出した、止まった、ユーザーの顔がすぐ目の前、手を目の前に出された。
   - 反応: 動くおもちゃは目で追う。出来事は会話（GPT-Live）へ参考情報として伝え、Jev利用中はJevが表情・動きを選ぶ（`perception.visible` と `sawEvent` を渡す）。Jevなしでは首をかしげる・わくわく・止まったボールを見に行く・照れて目をそらす等の端末内ルール。
2. **目で見て説明**（OpenAIキー、設定でOFF可）: 「何が見える？」「これ見て」と言われると、キャラの目の位置のカメラで部屋のCG画像（512×320 JPEG）を撮り、OpenAIの画像入力で説明を作ってGPT-Liveへ渡し、見たままを声で話す。送るのはアプリ内のCG画像で、現実のカメラ映像ではない。

## ロボット声

GPT-Liveから届いた音声に端末内でエフェクト（58Hzのリングモジュレーション、6msの共鳴エコー、軽い量子化）をかける。設定 → 声と音量 →「ロボット声: ロボのみ／全員／OFF」（既定はロボのみ、すぐ反映）。ロボの話し方指示も、区切りのはっきりした少し機械的な口調に変更。

## 設定

設定 → キャラクター:「指示どおりに動く」「視覚（見えた物に反応）」「目で見て説明（画像をOpenAIへ）」のON/OFF。
