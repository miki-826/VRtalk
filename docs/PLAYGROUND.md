# おもちゃ遊びとモデル別の声（2026-10-24）

- PC: Uを押している間だけ話す。離すとマイク送信が止まる。初回は接続待ちになる。文字入力中は無効。
- Quest: 右Aボタン、または画面のPTT長押しを継続使用。
- 声: モデル別の既定音声と発話指示を組み合わせる。しろは穏やか、こはくは明るく、ロボは明瞭でリズミカル。音声自体の実聴評価は未実施。
- 設定 → Voice →「モデルに合う声へ戻す」で手動音声指定を解除できる。次の接続から反映。
- モデル追加時はCharacterProfile.speechStyleで話し方を設定。旧プロフィールはid別の既定値を使用。

「いっしょに遊ぶ」→「おもちゃを置いて遊ぶ」を開き、種類を選んで空いている床をクリックする。Questではレーザーとトリガー／ピンチを使う。ボール・積み木・回転おもちゃを最大8個まで配置できる。

「選んだ物で遊ぶ」でキャラクターが障害物を避けて近づき、しゃがんでおもちゃを動かす。「次のおもちゃを選ぶ」で切り替え、「動きを止める」「すべて片づける」で操作を取り消せる。ボールの弾み・積み木の揺れ・回転は軽量な演出アニメーションで、物理的な手指の把持ではない。

（2026-10-24更新）遊び中も会話接続を維持する。声や文字で遊び方を頼める。詳細は MOTION_VISION.md。配置した物は家具認識・経路探索にも反映される。配置はその部屋のセッション中だけ保持され、部屋の切り替えや再起動では復元しない。アプリのPause／Focus喪失、画面移動時には遊びを停止する。

使用したおもちゃの形状はUnityのプリミティブから生成し、追加の外部アセットは使用していない。

発話指示の参考: https://developers.openai.com/api/docs/guides/live-prompting
